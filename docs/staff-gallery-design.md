# スタッフ用装着事例登録

複数PCでログインして写真と登録内容を共同管理する。現在の公開ギャラリーと同じSitesに `/admin/` を追加し、公開先の閲覧範囲は維持する。

- ChatGPTのプラットフォーム認証と、サーバーで確認するスタッフ許可リスト。管理者メールはSitesのシークレットで設定し、ソースに記載しない。
- D1に下書き・公開版・編集番号・操作履歴・スタッフ権限、R2に写真を保存。公開版と下書きは別に保持する。
- 登録担当は下書き保存と確認依頼。公開担当・管理者は確認後に公開・取り下げ。管理者はスタッフ追加と権限変更。
- 車種、ブランド、シリーズ、正式な色名、検索用の色系統、掲載品番・型式、商品URL、掲載コメント、写真順を登録。
- 色系統を商品名から機械的に断定しない。写真の対応と公開許諾を確認してから公開する。
- 同時編集は編集番号で検知し、409で停止。公開操作も現在の編集番号が一致する場合のみ実行。
- 公開APIは公開版だけを返す。写真も公開版に使用されている場合だけ匿名アクセスを許す。
- 元の2,895件は固定データとして維持し、登録画面で公開した内容を追加・上書きする。更新に毎回のGit操作や再デプロイは不要。
- futureshopへの移設用に公開データを出力する。futureshop管理画面への自動アップロードは今回の連携に含まれない。

検証: 未ログイン・未登録ユーザー・担当者の公開拒否、写真の非公開、同時編集、公開後の下書き変更、取り下げ、旧データ互換、SP/PC入力、アップロードと永続保存を確認する。
