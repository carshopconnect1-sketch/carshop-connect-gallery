# 公開ギャラリーのリンク点検（2026-09-25）

対象: `https://carshop-connect-gallery-renewal.masaruharuyama.chatgpt.site/`。調査開始時に公開中の `data/catalog.json` と作業コピーが同一であることを確認した。以下の修正はこの時点ではローカルの新しい版について記す。

## 結果

- 2,895件の装着事例から商品リンク・車種カテゴリの代替リンク、シリーズリンク、共通ナビゲーション、記事リンクを収集。重複を除く外部 URL 1,398件とページ内アンカー2件を点検し、アンカーの参照先は両方存在した。
- 店舗サイトへの GET の結果は HTTP 200 が454件、206 が3件、404 が33件、429 が908件。404 の33件はすべて旧データから推定した車種カテゴリの代替リンクで、例としてムーヴキャンバスの旧 `movecanvas` とアウディA3の旧 `a3` がある。429 はアクセス制限で、リンク切れの証拠ではない。
- 開けた商品ページのタイトルや店舗の車種一覧と写真の車種・ブランドを照合し、明確に誤誘導となる事例38件を特定した。例: A4アバント→A3商品、RX-8→トヨタiQ商品、Sandii事例→Refinad商品、ジムニーノマド→通常ジムニーの商品番号00113。該当IDと理由は `rejected-product-links-2026-09-25.json` に記録した。
- 旧車種カテゴリ推定を商品ボタンに使うのをやめ、店舗が公開している車種メニューにある300組のメーカー・車種リンクへ切り替えた。名称を読み替えたものも `vehicle-product-links-2026-09-25.json` に明記した。誤った38件の直接商品URLは外し、36件は対応する車種カテゴリ、残り2件はブランドのシリーズカテゴリへ案内する。該当品番を推測して置き換えていない。
- 修正後の2,895件の案内先は、直接商品2,632件、車種カテゴリ221件、シリーズカテゴリ16件、車種一覧26件。写真と商品が一致する確証がない場合は、ボタンの文言も「この商品を見る」ではなく「○○の商品を探す」などにしている。
- 編集コンテンツから装着事例へのリンクは現在のページパスを保持するよう変更した。将来 `/f/` 配下へ設置しても、サイトのトップへ誤遷移しない。

## 確認できた範囲

`npm run check`、`npm test`（26件）、データ整合性監査、`npm run build` は通過。公開ドメイン、店舗の車種一覧、代表的な商品ページ・記事ページは応答を確認した。

商品ページを全件開いて在庫・販売状態・年式・型式・グレード別適合まで確定することはできていない。直接商品リンクは残り2,632事例にあり、特に HTTP 429 になったURLの状態は未確認。車種カテゴリへのリンクも、適合や在庫を保証するものではない。購入前には店舗の適合表示または店舗への問い合わせで確かめる必要がある。
